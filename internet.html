Brief Summary

The internet is a global network that connects computers and allows data exchange using standardized protocols. Encoding transforms data into a specific format for compatibility and efficient transmission, such as Base64 for data storage. Encryption, on the other hand, secures data by converting it into an unreadable format using cryptographic algorithms, ensuring that only authorized users with the correct key can access the original information.

The Internet

  • Networks, Protocols, and Physical Connections: A network is a system of connected devices that communicate using protocols, which are standardized rules (like TCP/IP). Data travels through physical connections such as wires (Ethernet), fiber optics (fast light-based transmission), and Wi-Fi (wireless signals) to reach its destination.
  • Packet Switching, Routing, and Reliability: The internet uses packet switching, where data is broken into small packets that travel independently. Routers direct these packets along the best paths based on network conditions. This system ensures reliability, as packets can take alternate routes if a connection fails, ensuring the message still arrives.

Encoding

  • Encoding is the process of breaking down language into code using Binary, Decimals, ASCII and more. Binary is a base-2 number system using only 0s and 1s, fundamental for computers. Decimal is a base-10 system (0-9) used in everyday counting. ASCII (American Standard Code for Information Interchange) is a character encoding standard that represents text using binary values, where each character (like 'A' or '1') is assigned a unique 8-bit binary code.
