Brief Summary

The internet is a global network that connects computers and allows data exchange using standardized protocols. Encoding transforms data into a specific format for compatibility and efficient transmission, such as Base64 for data storage. Encryption, on the other hand, secures data by converting it into an unreadable format using cryptographic algorithms, ensuring that only authorized users with the correct key can access the original information.

The Internet

  • Networks, Protocols, and Physical Connections: A network is a system of connected devices that communicate using protocols, which are standardized rules (like TCP/IP). Data travels through physical connections such as wires (Ethernet), fiber optics (fast light-based transmission), and Wi-Fi (wireless signals) to reach its destination.
  • Packet Switching, Routing, and Reliability: The internet uses packet switching, where data is broken into small packets that travel independently. Routers direct these packets along the best paths based on network conditions. This system ensures reliability, as packets can take alternate routes if a connection fails, ensuring the message still arrives.

Encoding

  • Encoding is the process of breaking down language into code using Binary, Decimals, ASCII and more. Binary is a base-2 number system using only 0s and 1s, fundamental for computers. Decimal is a base-10 system (0-9) used in everyday counting. ASCII (American Standard Code for Information Interchange) is a character encoding standard that represents text using binary values, where each character (like 'A' or '1') is assigned a unique 8-bit binary code.

Encryption

  • Encryption is the process of converting data into a coded format to prevent unauthorized access. It ensures confidentiality by making information unreadable to anyone without the proper decryption key, protecting sensitive data from cyber threats, theft, and unauthorized modifications.
  • Symmetric Encryption: Symmetric encryption is a method of encrypting data using a single key for both encryption and decryption. It ensures fast and efficient data protection, making it ideal for securing large amounts of information. However, its security relies on keeping the shared key confidential to prevent unauthorized access.
  • Asymmetric encryption uses two mathematically related keys often generated by a assymetric encryption method: a public key for encryption and a private key for decryption. This method enhances security by eliminating the need to share a single key, reducing the risk of key compromise. Compared to symmetric encryption, asymmetric encryption is slower but more secure for key exchange, while symmetric encryption is faster and better suited for encrypting large amounts of data.

HTTPS and Security

  • HTTPS (HyperText Transfer Protocol Secure) secures data transmission using SSL/TLS (Secure Sockets Layer/Transport Layer Security) encryption. When a user connects to a website, the server and client establish a secure connection through a process called the TLS handshake, where they exchange encryption keys. This enables end-to-end encryption, ensuring that data sent between the user's browser and the website remains private and protected from interception, tampering, or attacks like man-in-the-middle (MITM). TLS also provides authentication using digital certificates, verifying the website’s legitimacy to prevent fraud.
